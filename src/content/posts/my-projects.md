## 一、先把话说在前面

这十一个项目，绝大部分是**给自己写的**。没有需求文档，没有排期，也没有「用户增长」这回事。

它们通常始于一个很具体的不爽：

- 想给朋友发一段话，但不想存到任何服务器上 → 于是有了文字加密
- 写 Markdown 的时候老要切窗口看效果 → 于是有了 MD 编辑器
- 和 AI 聊到一半内容被改掉了，想找原来的版本 → 于是有了 DeepSeek 插件
- 服务器里有人用各种谐音和形近字绕过滤 → 于是有了 Chat Filter

所以它们的形态都不太一样：有的是纯静态网页，有的是服务端插件，有的是装在自己浏览器里的扩展。
共同点只有一个——**它们都真的在用**。

## 二、游戏与服务器

这一类都是 Minecraft 相关的，跑在服务端或者客户端。

### MCAI 版

> 状态：开发中

用ai从零开始做的MC网页版

目前还在多轮迭代，可通过下方的连接在线游玩

- 项目主页：`https://example.com/mcai`
- 游玩入口：`https://example.com/mcai/docs`

### Chat Filter · Fabric 服务端聊天过滤

> 状态：已上线

服务端屏蔽词插件，起因是服务器里总有人用变体写法绕过滤。

做的时候重点不在「匹配关键词」，在**识别变体**：leet 写法（`f u c k` / `f*ck` / `fuckkk`）、拆字、夹杂符号，都要能认出来。
另外支持正则词库、替换或直接拦截两种模式；违规累计到阈值后自动禁言或踢出，带白名单和管理员通知。
告示牌和铁砧里输入的文字同样会被检查——这两个地方经常被漏掉。

- 项目主页：`https://example.com/chatfilter`
- 下载：`https://example.com/chatfilter/download`

### Chest Menu · 可视化菜单系统

> 状态：已上线

类似 ChestCommands 的东西：用配置文件画出箱子菜单，玩家 `/menu open <id>` 打开，管理员 `/menu reload` 热重载。

比原版多的是**权限变体**——同一个菜单 id，不同权限的玩家看到的按钮和内容是两套。
服务器做活动页、新手引导、商店入口都用它。

- 项目主页：`https://example.com/chest-menu`

### Whitelist Pro · 进阶白名单管理

> 状态：已上线

原版白名单只有在正版验证下才能使用，本模组可将其用于离线版本

适合那种要对外放人、但又不想整个服务器都开放的小型私服。
目前跑在 1.21.11 上，还在打磨审核流程。

- 项目主页：`https://example.com/whitelist`

## 三、Web 工具

这一类都是**打开就能用**的静态页面：没有账号、没有数据库、没有后端。

### 文字加密

> 状态：已上线

在浏览器里给文字上锁。输入一段话和一个密码，得到一串密文；对方把密文贴回来、输入同一个密码，就能还原。

关键在于**全程本地运算**：加解密都在你的浏览器里完成，一个字节都不会发到服务器。
代价是密码丢了就真找不回来了——这是设计选择，不是缺陷。

- 立即使用：`https://example.com/text-lock`

### MD 编辑器 · Markdown 实时预览

> 状态：已上线

左边写、右边看，滚动位置双向同步。支持代码高亮、表格、任务列表、数学公式。
写的东西自动留在浏览器本地，刷新或者误关标签页都不会丢。写完可以导出 HTML 或者原始 Markdown。

我这篇文章的初稿就是先在它里面写完的。

- 立即使用：`https://example.com/md`

### 思维导图 · 节点式发散梳理

> 状态：已上线

从一个中心点往外长。拖节点、改文字、换配色，键盘就能完成大部分操作。
适合开会记提纲、拆需求、理一篇文章的骨架，做完导成图片或者缩进大纲。

写东西卡住的时候，我一般会先在这上面画二十分钟，比硬想有用。

- 立即使用：`https://example.com/mindmap`

### 决策树编辑器 · 分支逻辑可视化

> 状态：已上线

把「如果这样，那就那样」画出来。每个节点是一个判断，每条边是一个结果。

真正好用的地方是它能让**死角**暴露出来：总有一条分支你从来没想过，画上去才发现「哦这里没处理」。
导出的 JSON 可以直接喂给代码里的判断逻辑。

- 立即使用：`https://example.com/decision-tree`

### 网页钢琴 · 键盘即兴演奏

> 状态：已上线

打开就能弹，电脑键盘映射成琴键。支持长按连音、八度切换、录音回放，手机上是触摸屏。

做它纯粹是因为「想弹两下」的时候，找一个没广告、不用注册、不会弹窗的网页太难了。

- 开始弹：`https://example.com/piano`

## 四、本地工具

### DeepSeek 插件状态：本地自用

给 `chat.deepseek.com` 配的 Chrome 侧边栏扩展。

具体来说：

- 每一条消息的每一次改写都单独存成历史版本，旧版本不删，标成「已变更」
- 同一轮回答如果有多个版本，可以做词级 diff，逐字看清这次删了什么、加了什么
- 可以给任意时刻的对话存一个本地分支，分支之间互不干扰
- 支持全文搜索，命中处时间线和结构树同步高亮
- 一键导出 Markdown、一键导出/恢复 JSON 备份

数据全部写进浏览器的 IndexedDB，**一次网络请求都不发**。
需要说清楚的是：服务端真删掉的数据它也捞不回来，它只能保住你看见过的部分——这点在文档里写得很直白，不画大饼。

## 六、几条一直在坚持的东西

### 能纯前端就不上后端

文字加密、MD 编辑器、思维导图、决策树、网页钢琴，全是静态页面。
没有数据库、没有账号系统、没有服务器账单。关掉标签页，数据跟着一起走。

对工具来说这不完全是缺点——省掉了「我的东西到底存在哪个机房」这种焦虑。

### 数据默认留在本地

DeepSeek 插件连网络请求都不发。这类工具的设计前提应该是：**用户的数据不是产品的燃料**。

### 先能用，再好看

每个项目的第一版都丑得不能看，但能用。
之后每一版都针对具体的一条问题去改：这次是滚动不同步，下次是深色模式下字看不清。
改完立刻验证，验不过就退回上一版重来——而不是「先重构一遍再说」。
